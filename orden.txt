# Orden manual de los vídeos en la web.

# Una ruta por línea (dentro de /videos), de arriba abajo tal como
# quieres que aparezcan. Para reordenar, mueve las líneas de sitio y
# vuelve a ejecutar:  node generar-datos.mjs
#
# Los vídeos que no aparezcan aquí (por ejemplo, si añades uno nuevo)
# se colocan al final automáticamente.
#
# ---------------------------------------------------------------
# POR QUÉ ESTÁN ASÍ COLOCADOS (importante si tocas el orden)
#
# La rejilla no deja huecos si cada bloque de vídeos verticales tiene un
# número de piezas que cuadre con las columnas: 12, 6 y 4 (3 columnas los
# dos primeros, 2 el último; en móvil son 2 columnas y los tres cuadran).
#
# Los bloques los separan: (a) el nombre grande del centro, que cae justo
# a la mitad — tras el vídeo 12 — y (b) Benajarafe, el único vídeo
# apaisado, que ocupa una fila entera él solo.
#
#   vídeos  1-12  → bloque de 12   (antes del nombre)
#   vídeos 13-18  → bloque de  6
#   Benajarafe    → fila apaisada
#   vídeos 20-23  → bloque de  4
#
# Si añades o quitas vídeos, procura mantener bloques con un número par
# de piezas (mejor aún si es múltiplo de 6) o volverán a salir huecos.
# Las categorías van alternadas a propósito para que la rejilla no
# muestre tres vídeos seguidos del mismo tipo.
# ---------------------------------------------------------------
